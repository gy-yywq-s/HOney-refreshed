# Round 03 — typographic reset

Round 02 failed because semantic diagrams were added to an unrefined generic skeleton. Round 03 starts from letterform quality, in monochrome, and treats double-reading or campus associations only as possible emergent readings.

Process:

1. Establish a light, calm, slightly lively typographic skeleton.
2. Test one shared transformation at a time: cut, hinge, ligature, counter, or attached graphic.
3. Check the word at display, header, and small UI sizes before color.
4. Use ImageGen only for isolated structural fragments. Redraw any selected fragment as deterministic vector geometry.

Promising clues retained from the rejected round:

- Concept 04: letters can connect spatially.
- Concept 05: one repeated cut/fold can unify the whole word.
- Concept 07: a joint can act as a graphic grammar.

Nothing from the rejected wordmarks is treated as a production candidate.
