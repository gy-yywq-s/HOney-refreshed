# HOney open-loop spectrum — draft asset pack v1

## Direction

- Shape: Open day loop from concept A.
- Surface: Pale sky `#EAF4F6` from concept B.
- Loop segments: blue `#5E9ED6` from C, green `#57A47A` from D, amber `#F5AE54` from F, smoky plum `#745170`, and graphite `#25354A`.
- Wordmark: graphite letter skeleton with the same spectrum confined to structural joints.

This is a draft asset pack and is not installed into the app or Web project automatically.

## Contents

- `source/`: editable SVG masters.
- `ios/AppIcon.appiconset/`: default, dark, and tinted 1024 px icons plus Xcode metadata.
- `ios/Wordmark.imageset/`: transparent 1x/2x/3x wordmark PNGs plus Xcode metadata.
- `web/`: PWA icons, favicons, web companion master, and wordmark.
- `preview.png`: visual inventory.

Apple icon sources are full square, opaque images; iOS applies the platform mask. The Web companion uses a neutral globe badge and keeps the primary mark inside the maskable safe area.
