# Infinite colour exploration

Five deterministic SVG directions using the open-loop spectrum palette on the Day Dial pale-sky surface.

1. Open spectrum — literal infinity with one unresolved gap.
2. Möbius spectrum — closed ribbon with one visible flip.
3. Unfinished handoff — coloured contributions get smaller toward an open remainder.
4. Two endless paths — two complementary paths keep exchanging foreground.
5. Beyond frame — the system continues outside the icon boundary rather than closing inside it.

These are visual explorations, not installed assets.
